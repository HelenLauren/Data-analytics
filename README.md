# Data-analytics 

### 1. Context

Health

### 2. Initial question

 Which factors are associated with hospital readmissions? 
(Quais fatores estão associados a readmissao |retorno do paciente em até 30 dias após alta| de pacientes no hospital?)

### 3. Required data

- Patient demographics (age, Gender, etc)
- Previous hospitalizations
- Diagnosis
- Length of hospital stay
- Medications
- Chronic diseases
- Treatment received
- Follow-up appointments 
- Whether the patient was readmitted

### 4. Classify the data

Age - Structured
Gender - Structured
Diagnosis - Structured
Hospitalization dates - Structured
Medications - Structured
Medical reports - Unstructured
Doctors notes - Unstructured

### 5. Type of analytics

Predictive analytics
